# VoRush · 英语单词塔防

给小学低年级孩子的"学习优先"塔防游戏：想守住哨站，先学会单词。

- **学习优先**：战前认识新词 → 波次之间固定答题赚金币 → 用金币建塔。单词不认识，塔就建不起来。
- **Kingdom Rush 式推进**：一张 3D 微缩岛屿大地图，通关一关解锁下一关，可以随时回去重玩任何已解锁的关卡。
- **每关地形不同**：1-3 关一条入侵路径；4-6 关两条路共守一座哨站（含分岔与合流）；7-9 关两条路两座哨堡，需要两边布防。
- **儿童友好**：无血腥表现、无复杂数值面板，按钮触控区 ≥60pt，横屏 iPad 优先。

技术栈：**TypeScript + three.js + Vite**，运行时依赖只有 `three`。岛屿地形、塔、敌人、哨站全部用基础几何体程序化拼装，无外部模型/贴图资源。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器（默认 5173 端口）
npm test           # vitest 单元测试
npm run build      # 类型检查 + 生产构建（输出 dist/）
```

**iPad 真机试玩**：开发服务器启动后，用局域网地址访问，如 `http://<你的IP>:5173/`。加 `?debug=1` 可显示 FPS 与单局计时，供真机性能走查。

## 玩法循环

```
开始 → 3D 大地图选关 → 战前认识新词 → 布防（点旗建塔）
  ↑                                        ↓
  ← 返回地图（解锁动画） ← 三星结算 ← 三波战斗（波间答题赚金币）
```

- **三波敌人**：哥布林（普通）、野狼（快）、哥布林队长（第 3 波压阵）。
- **两种塔**：弓箭塔（打得快）、骑士营地（拦住怪物），各三级升级。
- **三星评价**：通关星（守住）、认识星（新词都答对过）、复习星（新词记得牢）。
- **守护目标**：每条路尽头一座哨站，全部哨站共享 ❤️6 生命池，任一处被突破扣同一池，扣光失败。

## 关卡与词库

关卡序列绑定学校默书词表（`src/data/words.ts`，词表原件在 `00_input/`）：

| 关卡 | 词包 | 地形 |
|---|---|---|
| 1 | 动物伙伴 | 1 条路 · 草原哨站 |
| 2-4 | T1 默书 1-3 | 1 条路（北岸长弯 / 回旋道…） |
| 5-7 | T2 默书 1-3 | 2 条路共守 1 座（分岔口 / 双滩合流…） |
| 8-9 | T3 默书 1-2 | 2 条路 2 座石堡（两侧登陆 / 长征分岔） |

敌人生命/速度/数量随关卡缩放。每关的地图数据（路径折线、哨站、塔位、岛屿形状）手写在 `src/data/levelMaps.ts`，岛屿海岸线按关卡种子程序化生成，逐关不同。

**单词发音**由 macOS `say` 批量生成：

```bash
bash scripts/gen-audio.sh   # 缺失的 m4a 会自动补齐（Samantha, 145 wpm）
```

## 目录结构

```
src/
  data/       纯数据：词库、关卡序列、9 张地图、难度、波次、经济、进度键
  combat/     战斗纯逻辑：路径(弧长参数化)、敌人、塔、出怪、洗牌袋分路
  learning/   学习记录与三星评价
  quiz/       出题与答题 UI、单词音频
  session/    单局状态机（教学→布防→战斗→练习→结算）
  economy/    金币钱包
  events/     补给箱事件
  game/       Game（流程编排）与 LevelController（单局驱动）
  world/      three.js：渲染底座、地形、低模工厂、大地图、补间、资源释放
  ui/         DOM 覆盖层（HUD、建塔菜单、结算、教学、地图标签）
tests/        vitest 单元测试（纯逻辑，不渲染）
openspec/     规格驱动开发：specs/ 主规格，changes/ 变更归档
```

进度与学习记录存于浏览器 localStorage（`vorush.clear.<关卡id>` / `vorush.records.<词包id>`），无后端、无账号。

## 规格驱动开发（OpenSpec）

每个功能走一轮 OpenSpec 流程：`proposal → design → tasks → delta 规格`，完成后同步主规格并按日期归档到 `openspec/changes/archive/`。当前 12 个主规格描述了从战斗规则到大地图行为的全部系统约定，改行为前先看对应规格。
