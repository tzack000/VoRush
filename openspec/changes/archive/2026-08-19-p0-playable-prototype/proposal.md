# P0 可玩原型：1-1 草原哨站

## Why

VoRush 是一款"学习优先"的儿童英语塔防游戏（目标用户：小学一、二年级，首发 iPad 横屏）。核心玩法设计 v0.1 已确认，但在投入完整动物主题（P1）之前，必须先做一个最小可玩原型验证核心循环：孩子是否理解"答题获得金币"、学习与塔防交替是否顺畅、是否愿意主动点击补给箱、单局能否控制在约 8 分钟。P0 只做 1-1 草原哨站一个关卡。

## What Changes

- 从零搭建 Web 原型工程（TypeScript + Phaser，横屏，可在 iPad 浏览器试玩）
- 实现完整单局流程：战前认识 4 个新词（cat、dog、bird、fish）→ 初始金币布防 → 三波战斗，波间固定单词练习 → 击退全部敌人 → 三星结算
- 实现两种题型：听音选图、看图选词；答错不惩罚，提供引导完成（提示完成后仍有基础金币）
- 实现两种防御塔：弓箭塔、骑士营地（各三级线性升级）
- 实现三种敌人：哥布林、野狼、哥布林队长（关卡末尾小首领）
- 实现纯学习经济：建造/升级金币全部来自答题，击杀敌人不掉金币
- 实现补给箱战斗事件：只显示图标+提示音，玩家点击后完全暂停战斗再答题，忽略无惩罚
- 实现三星结算：通关星、认识星、复习星；获得第一颗星即视为通关
- 儿童交互约束：主要按钮 ≥60pt、一屏最多 4 个答案、指令语音可重播、答题时完全暂停战斗、不用夸张红叉/刺耳音效

明确不做（首版范围控制）：英雄、字母排序题型、魔法塔/炮塔、精英弱点、Boss 护盾、王国地图、工坊强化、复习巡逻、单词成长状态持久化、间隔复习调度。

## Capabilities

### New Capabilities

- `word-learning`: 战前认识与波次间固定单词练习；听音选图、看图选词两种题型；不惩罚答错、提示引导完成；答题产生金币
- `learning-economy`: 纯学习金币经济——金币来源、数值表、失败保护（初始资金足够建一座塔、提示后仍有金币）
- `tower-defense-combat`: 塔防战斗核心—— enemy 路径移动、三波波次、弓箭塔与骑士营地（含三级升级）、哥布林/野狼/哥布林队长、出口生命与失败判定
- `battle-events`: 补给箱可选战斗事件——出现提示、点击暂停答题、金币收益、忽略无惩罚、每波至多 1 个
- `level-session`: 1-1 关卡完整会话流程（战前学习→布防→三波→结算）、节奏控制（学习 30-45s / 建造约 15s / 战斗 45-60s）、三星评价

### Modified Capabilities

（无——首个 change，无既有规格）
