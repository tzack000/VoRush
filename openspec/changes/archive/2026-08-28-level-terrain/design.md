# 关卡地形 · 设计

## Context

地形与战斗数据此前是分离的：`data/level.ts` 只有单条折线 + 8 个塔位，`islandHeight` 是无参纯函数，岛屿只在 `IslandScene` 构造时建一次。要"每关地形不同"必须打通：关卡定义 → 岛屿形状 → 路径 → 哨站 → 塔位。

## Goals / Non-Goals

**Goals**：每关地形、路径数、哨站数递进；哨站看得见；随机分路不扎堆；换关不泄漏 GPU 资源；第 1 关外观与手感尽量不变。

**Non-Goals**：不做运行时寻路/动态路径；不做相机跟随或缩放手势；不动平衡数值（7-9 关难度另开一轮调参）；不做每关不同敌种（词包绑定已有难度曲线）。

## Decisions

### 1. `islandHeight` 用模块级"当前形状"而不是参数透传

抽出纯函数 `islandHeightWith(shape, x, z)`，`islandHeight(x, z)` 签名不变、读 `coords.ts` 的模块级 `active` 形状。`setIslandShape` 只允许 `IslandScene.buildTerrain` 首行调用。

**Why**：`islandHeight`/`worldOf` 在 terrain/IslandScene/LevelController/Game 六处共 20+ 个调用点，透传要改一圈签名；同一时刻只存在一座战斗岛屿（大地图走独立的 `createMapIsland`）。配套 `terrainReady` 断言：`LevelController` 构造时地形未建好就抛错，把"顺序错了模型贴旧高度"这种静默 bug 变成显式崩溃。

### 2. 分岔/合流用"共享前缀/后缀的折线"表达

两条折线写同样的前几个点，敌人各绑定一条完整折线，走起来自然"一起走然后分开"。`Path` 本就每实例独立，弧长参数化下共享前缀上位置完全一致（有单测锁定）。

**Alternative rejected**：运行时"分岔点选择"——要给敌人加状态机、给孩子加"怪会拐弯"的预示，复杂度远超收益。

### 3. 随机分路 = 洗牌袋（copies=2, maxStreak=2）

**Why**：纯随机在一波 6-13 只怪时可能连出 4-5 只同一边，直接打穿没设防的一侧——对一年级孩子是"运气输"。袋 2×路径数保证每个完整袋 2:2，maxStreak 保证不连出 3 只。

**明确放弃的属性**："任意连续 4 只恰好 2:2"要求 `x[i+4] ≡ x[i]`（由滑动窗口计数相减可证），序列退化为周期 4，随机性归零。跨袋边界的窗口可以是 3:1，这是保留不可预测性的必要代价。

### 4. 出怪口必须真的在水里

首点放在岛外，怪从海滩爬上来。但每关海岸线是程序生成的，固定坐标（如 x=-40）在某一关可能刚好落在平台上——第 2、3、4 关都踩过。统一外推到 x=±180/1460、y=-200：归一化半径 ≥ 1.08，在最不利谐波下高度仍 < 2.5，对全部形状稳健。这条约束进了单测。

### 5. 相机不动，靠数据自证

实测 iPad 4:3 下可玩元素横向可用到 x2d ∈ [25,1255]、哨站模型顶部 NDCy 仅 +0.42。所有手写坐标约束在 [120,1160]（保守值），并由单测 + 浏览器断言（`spotScreenPos`/`goalScreenPos` 必须落在视口内）双重锁定。

### 6. 资源释放：共享材质打标，倒影不 dispose geometry

- `models.ts`/`mapProps.ts` 的模块级材质缓存打 `userData.shared = true`，`disposeObject` 跳过——误释放会让后续所有关卡的敌人/塔变黑。
- `createReflection` 复用 `island.geometry`：只能释放倒影自己的材质，geometry 由岛屿那边统一释放。
- 实测进出关卡 `sceneChildren` 逐字节一致（40 → 失败 → 返回 → 再进 → 40），无泄漏。

### 7. 队长重叠 bug 的修法

两处配合：`WAVES` 里 captain 组 `intervalMs: 0 → 1200`；`scaleWaves` 只对 `count > 1` 的组加 `countBonus`。后者是语义修正——队长是压阵精英，"难度提升"应体现在小怪变多而非精英堆叠。

## Risks / Trade-offs

- **7-9 关难度断崖**：总怪量不变但分摊两路，塔的覆盖密度腰斩，叠加 `hpMult` 2.2。已留三个旋钮（按优先级）：`LevelMapDef.lifePool`（双路关给 8）→ `countBonus` 改 `floor((index-1)/3)` → 双路关起始金币加成。**结构落地后单独一轮调参，不与本次混在一起。**
- **手写坐标依赖程序化海岸线**：`islandShapeFor` 的随机数被改动会让手写坐标失效。单测对 9 组形状参数做了快照，改 seed 会立刻红灯。
- **第 1 关行军时长缩短**：终点从水下 [1320,160] 挪到陆上 [1075,205]，路径 2360→2260px（出怪口同步外推），哥布林行军约 -2s，第 1 关略变难。试玩时留意。
