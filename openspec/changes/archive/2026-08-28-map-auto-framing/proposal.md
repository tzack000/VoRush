# 进入地图自动取景全部已解锁关卡

## Why

大地图上线后发现一个可用性问题：进入地图时相机固定对准"当前该玩的那一关"，已经通关的关卡被推出画面外（标签 `opacity: 0`）。孩子看不到自己打过的岛，也就不知道可以回去重玩——即使点了也能进。iPad 上不会想到要拖动地图去找，等于"自由重玩已解锁关卡"这条形同虚设。

用户确认的要求：进入游戏之后显示大地图，玩家可以自由选择从**已经解锁的任意关卡**开始。

## What Changes

- 进入地图时相机改为**自动取景**：框住全部已解锁关卡（已通关 + 当前关），外加紧随其后的第一个锁定关卡做诱饵。
- 相机新增"拉远系数"：取景区装不下时才逐步拉远，早中期岛屿维持原尺寸；进度越靠后相机越慢慢拉远。
- 取景用**投影试算**求解（把候选缩放一代进去投影，看是否落进安全框），不写死俯角三角常数——换 iPad 屏幕比例、改岛屿坐标或改 fov 都不用重新标定量。
- 解锁动画的相机动作从"平移到新解锁的岛"改为"重新取景"（新岛同样被纳入画面，同时保留刚通关的那座岛）。
- 拖拽平移的手感跟随缩放调整（拉远时同样的手指位移对应更大的世界位移）。
- 删除 `focusCurrent` / `panTo`（已被取景取代）。

## Impact

- 修改规格：`world-map`（新增"进入地图自动取景"要求，更新解锁动画的相机动作）、`pack-selection`（进入地图时对准当前关卡 → 取景全部已解锁关卡）。
- 影响代码：`src/data/mapLayout.ts`（新增 `unlockedFrameIndices`）、`src/world/WorldMap.ts`（相机缩放与取景求解）、`src/game/Game.ts`（进入地图走取景）、`tests/mapLayout.test.ts`（取景关卡集合断言）。
- 纯相机行为改动，不影响战斗、经济、学习与进度数据。
