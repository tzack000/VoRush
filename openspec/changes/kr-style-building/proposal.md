# Kingdom Rush 式建造交互

## Why

当前建造流程（侧边建造菜单 → 选塔型 → 点塔位，且仅限布防阶段）操作链路长、与战斗割裂。用户希望对齐 Kingdom Rush 的经典交互：塔位插旗、点旗弹出建塔菜单、随时可建。这也更符合儿童直觉（目标就在眼前，无需记忆两步操作）。

## What Changes

- 塔位表现：空闲塔位放置一面旗帜（低模旗杆+旗面），替代现有光圈
- 建造交互：点击旗帜 → 在该塔位旁弹出建塔菜单（塔型卡片：emoji/名称/儿童提示/价格，金币不足置灰）→ 点卡片立即建造；点击菜单外区域关闭
- 建造时机：**任何阶段**（布防/战斗/练习外的战斗进行态）只要金币足够即可建造与升级；建造菜单打开不暂停战斗
- 移除：侧边建造菜单、底部"建造 🔨"按钮、"先选塔型再点塔位"两步流程
- 升级交互：点击已建塔弹出升级按钮（现有），同样放开到战斗阶段
- 首次教学引导更新为：点旗子 → 选弓箭塔 → 点开始

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `tower-defense-combat`: 建造/升级交互与时机——塔位旗帜、点旗弹菜单、任何阶段金币足够即可建造与升级
- `dom-ui-layer`: 新增锚定塔位的弹出式建塔菜单（屏幕坐标定位、视口内防��出、菜单外点击关闭）

## Impact

- 代码：LevelController 建造流程重写（删 buildMenu/selectedTowerDef）、新增建塔弹窗组件、models.ts 新增旗帜模型、教学步骤更新
- 规格：玩法规则（价格/金币/失败保护）不变，仅交互路径变化
- 测试：交互类逻辑少，靠浏览器冒烟验证；既有单测不受影响
