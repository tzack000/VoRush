# 词包分级与关卡递进

## Why

当前 8 个词包平铺在词包选择页，玩家自由选择，缺少递进结构。用户要求：词包按难度分级、绑定到有序关卡、进入关卡自动加载对应词包、越往后难度越大。这也让战斗难度与学习量同步递进，符合设计文档"主题词包对应王国区域"的结构。

## What Changes

- 新增关卡序列：8 个有序关卡，每关绑定一个词包（第 1 关动物伙伴教学关 → 第 2~8 关 T1D1~T3D1）
- 难度递增：后续关卡敌人生命提升、出怪数量增加、移动速度小幅提升（按关卡序号乘区）
- 解锁规则：第 1 关默认解锁；通关第 N 关（获得通关星）解锁第 N+1 关；未解锁关卡置灰不可进
- 词包选择页改为关卡选择页：显示关卡序号、词包名称、星星、锁定状态；点击进入自动加载该关词包
- 通关标记、学习记录按关卡 id 存储（复用现有 per-pack 键，关卡与词包一一对应）

明确不做：不新增敌人类型与题型；不改变单局内部结构（三波、经济）；不做王国地图视觉（关卡页沿用卡片网格）。

## Capabilities

### New Capabilities

- `level-progression`: 有序关卡与词包绑定、难度递增参数（敌人生命/数量/速度缩放）、通关解锁规则、关卡选择界面（锁定态展示）

### Modified Capabilities

- `level-session`: 单局由关卡配置驱动——自动加载绑定词包，战斗使用按关卡缩放的波次
- `pack-selection`: 词包选择改为有序关卡选择，含锁定状态与解锁条件

## Impact

- 数据：新增 `src/data/levels.ts`（关卡定义与难度缩放）；波次缩放为纯函数（可单测）
- 代码：PackSelectView 改关卡页（锁定态）、LevelController 接收关卡配置、Game 接线
- 测试：新增波次缩放与解锁规则单测；既有测试不受影响
- 兼容：旧 `vorush.clear.<packId>` 标记沿用（关卡 id 与词包 id 一致）
